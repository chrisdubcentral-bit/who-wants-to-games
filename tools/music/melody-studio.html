Notes

Each note is name+octave/beats, e.g. F#4/1 is one beat, E4/.5 is half a beat, r/1 is a one-beat rest. | marks a bar and is only there to help you read it. Styles move the melody up an octave where it suits the instrument.

Chords, as chord:beats (D, G, A7, F#m, Bm, Em7…). They should add up to the same length as the melody.
